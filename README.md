更新清单：

1. 增加了全局ui
2. 为每个动态库存增加了当前产出消耗显示
3. 增加装备穿戴系统，可以把水罐、背包、护甲卸下（为了可以更快的获取能力，如连续渴死10次可以获得荒漠跳鼠能力）
4. 消息列表增加部分随机事件的说明，如黑死病死了多少村民
5. 近战攻击（挥拳、劈砍、刺刀）等可以自动攻击，在第一次攻击按钮按了后，后面会在本次战斗中自动释放
6. 遇敌后，敌人不会马上攻击，需等到玩家攻击后敌人才会开始攻击
7. 优化部分布局，库存中把资源，消耗品分组显示
8. 汉化了部分内容
